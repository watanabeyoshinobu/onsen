## アプリの概要

本作品をご覧いただきありがとうございます。
『湯のここち』は、私自らがスーパー銭湯を巡り、その詳細な情報を発信することで、誰でも気軽に立ち寄れるようなサービスを目指して作成しました。
また、投稿機能を通じて、温泉好きなユーザー同士が楽しく交流し、盛り上がれるようなコミュニティスペースも提供しています。
公式ドキュメントや技術記事などを参考に、インフラ構築からフロントエンドまで独学で開発しました。

アプリケーションURL: [湯のここち](https://www.yunokokochi.com/)

## 湯のここち の開発背景
**本作品の開発経緯は大きく3つあります。**

1つ目は、私自身がスーパー銭湯が好きで、多彩な施設や美味しい料理、日帰りでリフレッシュできる素晴らしさをより多くの方に知ってほしかったためです。
「スーパー銭湯ってどういうところ？」「お風呂以外に何があるの？」といった疑問を解消し、スーパー銭湯の魅力を存分に伝えるため、ブログ風の紹介サイトとして制作しました。

2つ目は、現代の「ストレス社会」で日々疲労が溜まっている皆様に、少しでも安らぎを提供したいという思いです。
遠くの温泉地まで行かずとも、近場のスーパー銭湯で温かいお湯に浸かり、美味しいものを食べ、優雅なひとときを楽しんでリフレッシュしてほしい、そしてまた明日からの活力を養ってほしいという願いを込めています。

3つ目は、温泉好きなユーザー同士が楽しく交流できる「憩いの場」を提供したいという思いです。
単なる情報発信サイトにとどまらず、同じ趣味を持つ方々がおすすめの施設を共有したり、感想を語り合って盛り上がれるコミュニティスペースがあれば素晴らしいと考え、ユーザー同士が「繋がる」ことができる投稿機能を取り入れました。

## 機能一覧 / 詳細
### ユーザー機能
* 新規登録、ログイン、ログアウト、ユーザー情報編集
* ゲストログイン機能

### サイトに関する機能
* ユーザー同士の共有（投稿一覧、詳細表示、投稿、編集、削除機能）

### フォロー機能(Ajax)
* フォロー、フォロー解除機能
* フォロー、フォロワー一覧表示機能

### お気に入り機能
* 投稿に「いいね」ができる（Vue.jsによるSPA化）
* お気に入りをした投稿のカウントの増減

### その他機能
* トップページの自動スライドアニメーション（ライブラリ不使用、素のJavaScriptで実装）
* 温泉施設を閲覧した際のアニメーション（JavaScriptで実装）
* ページネーション機能
* ハンバーガーメニュー
* モーダルウィンドウ
* Google Maps APIを利用した動的な地図表示

## こだわった点
**1. シンプルながらおしゃれな UI/UX**
誰でも手軽に利用できるよう、各スーパー銭湯の紹介・感想欄・ユーザー一覧・ログイン関係のページへの遷移をヘッダーとハンバーガーメニューに集約し、直感的な操作性を実現しています。
また、トップページにはライブラリを使用しないバニラJavaScriptを用いた自動スライドアニメーションを実装。「魅せる」UIに力を入れつつ、感想欄でユーザー同士が「繋がる」ことを意識した設計にしました。

**2. Google Maps APIを活用した動的な地図表示とセキュリティ対策**
各温泉施設の正確な位置を伝えるため、Google Maps APIを導入し、JavaScriptで緯度・経度（lat, lng）を細かく調整してピンポイントでマーカーを配置しました。また、APIキーは環境変数（`.env`）を用いて隠蔽し、GitHub等に漏洩しないようセキュリティ面にも細心の注意を払って実装しています。

**3. モダンな技術スタックの採用**
* Vue.js × Ruby on Rails による部分的なSPA化を実装し、スムーズな「いいね」機能を構築しました。
* Terraform × ECS × CircleCI × GitHub によるインフラのCI/CDパイプラインを構築し、効率的で安全なデプロイ環境を整えました。
